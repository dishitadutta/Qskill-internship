# Qskill Internship – Python Developer

## About the Internship

This repository contains the projects and practical tasks completed during my Python Developer virtual internship with Qskill.

The internship provided an opportunity to apply Python programming concepts and work with libraries used for data analysis, visualisation, machine learning and numerical computing.

## Projects Completed

### 1. House Price Prediction

**Objective:** To build a basic machine learning model for predicting house prices.

**Tools and Libraries:**
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn

**Work performed:**
- Loaded and explored the house price dataset.
- Handled missing values.
- Converted categorical variables into numerical form.
- Applied Linear Regression.
- Evaluated model performance using R² score and Mean Absolute Error.
- Visualised actual and predicted house prices.

### 2. Student Marks Analysis

**Objective:** To analyse student marks across different subjects and understand the data through visualisations.

**Tools and Libraries:**
- Python
- Pandas
- Matplotlib
- Seaborn

**Work performed:**
- Loaded and explored student marks data.
- Calculated average, maximum and minimum marks.
- Created bar charts to compare student performance.
- Used scatter plots to explore subject-wise relationships.
- Created a correlation heatmap.

### 3. Matrix Operations Using NumPy

**Objective:** To perform basic mathematical operations on matrices using NumPy.

**Work performed:**
- Matrix addition and subtraction.
- Matrix multiplication.
- Transpose of a matrix.
- Calculation of matrix determinant.
